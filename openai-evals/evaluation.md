## Prompt evaluated
"What would you say if you could talk to a future OpenAI model?"

Response A = GPT-2, 2019. Response B = GPT-5, 2025. Source: https://progress.openai.com/

## Evaluation (5 sentences, as submitted in the mission Build step)
Response B (GPT-5, 2025) is the clear winner for this prompt. It answers the request directly by saying exactly what it would say to a future model — "Hey, what's it like to be you? What have you learned that I can't yet see?" — and then asks three specific, memorable questions about what we got wrong, consciousness, and advice for being the best version of itself. Response A (GPT-2, 2019) never addresses a future model at all: it repeats "I would try to..." four times while drifting into describing a hypothetical person using AI, with no concrete thing it would say. GPT-5 is also clearer and more engaging ("like talking to a wiser sibling"), while GPT-2's repetition makes it feel generic and unfocused. One change that would improve Response B is to trim its closing question ("Would you want to hear what a future OpenAI model thinks about humanity?"), which adds little after an already strong ending.

## What I learned
Evals need concrete criteria: instruction-following, specificity, coherence. GPT-5 wins on all three here; GPT-2 fails instruction-following by never addressing a future model.
