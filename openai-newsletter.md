## What was built

"Teja's MLOps Weekly" in ChatGPT Work mode (signed in as pcteja1028@gmail.com, Teja Plus): a Builder-brief newsletter covering the previous 7 days in four sections — Production ML, LLM evaluation and observability, Python tooling, Open-source watch — 3–5 updates per issue, each with a "Why this matters" takeaway and source link, about a 3-minute read. Preview issue for November 16–22, 2026 covered vLLM 0.34.0, Langfuse 4.81.0, and Ruff 0.17.6. Scheduled task verified in ChatGPT: weekly Mondays at 8:00 AM Central Time, starting November 23, 2026, repeat on, end never, using public web search only.
