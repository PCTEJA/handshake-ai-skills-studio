## What was built

A reusable competitor snapshot generator for ZHuddle, a Python learning tool for UNT students built on small-steps lessons. It compares ZHuddle side-by-side with Codecademy, freeCodeCamp, and Khan Academy using only verifiable public facts, with sources and 22 Nov 2026 check dates in the fact log and unsupported items marked [UNKNOWN].

## Decision

ZHuddle should compete on focus — Python-only, small steps, UNT students — not breadth or price, because freeCodeCamp and Khan Academy already offer broad learning free, and Codecademy charges for career paths.

## Verified facts (22 Nov 2026)

- **Codecademy** (codecademy.com/pricing): Basic $0 always free (courses limited); Plus $14.99/mo billed annually or $29.99 monthly; Pro $19.99/mo billed annually or $39.99 monthly; catalog includes Python, web development, data science, AI.
- **freeCodeCamp** (freecodecamp.org/learn, /learn/python-v9/): free, donor-supported 501(c)(3); Python Certification teaches Python fundamentals, requires 5 projects to qualify for the exam and passing it, 588 steps.
- **Khan Academy** (khanacademy.org/computing/computer-programming): free, 501(c)(3) nonprofit, donation-funded; Computer programming course has 8 units in JavaScript, HTML/CSS, SQL, jQuery — no Python course was listed on that page, stated honestly.
- **ZHuddle:** Maker-stated (Python learning for UNT students, small-steps lessons); pricing [UNKNOWN] — no public pricing page cited.
